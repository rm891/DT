# 누리 아카데미 (프로토타입)

오리지널 몬스터로 만드는 비영리 육성/탐험 웹게임 뼈대예요.

## 스프라이트 규격

| 종류 | 파일 위치 | 크기 | 구성 |
|---|---|---|---|
| 알 | `assets/eggs/e1.png` ~ `e6.png` | **128×32** | 32×32 프레임 4장(가로): 대기1, 대기2, 금1, 금2 |
| 몬스터 | `assets/monsters/m001.png` ~ `m018.png` | **64×32** | 32×32 프레임 2장(가로): 대기1, 대기2 |
| 플레이어 | `assets/player/player.png` | **96×128** | 32×32 프레임, 가로 3칸(서기/걷기1/걷기2) × 세로 4줄(아래/왼쪽/오른쪽/위) |

- 배경은 **투명 PNG**, 바닥선은 프레임 맨 위에서 28px 지점(가이드의 파란 선)
- `monster/egg/player_blank.png`는 빈 캔버스, `*_guide_x10.png`는 10배 확대 가이드예요.
- 파일이 없으면 자동으로 임시 도트가 나와요. 같은 이름으로 넣으면 교체돼요.

## 클로드로 내 캐릭터 도트 만들기 (친구들용)

클로드에게 `player_blank.png`와 `player_guide_x10.png`를 올리고 이렇게 요청하세요.

> 이 규격(96×128, 32×32 프레임, 3열×4행: 아래/왼쪽/오른쪽/위 × 서기/걷기1/걷기2)에 맞춰서 내 캐릭터를 도트 PNG로 만들어줘. 투명 배경, 파스텔 톤, 1px 외곽선, 캐릭터 설정은 ___.
> 코드로 정확히 96×128 PNG 파일로 저장해줘.

완성된 PNG를 게임 하단 **내 스프라이트 넣기**에서 올리면 바로 적용돼요. (본인 브라우저에만 저장)
모두에게 보이게 하려면 `assets/player/` 등에 넣고 GitHub에 커밋하세요.

> 캐릭터는 직접 만든 오리지널로 해주세요. 공식 IP의 캐릭터나 추출한 스프라이트는 넣지 않는 걸 권장해요.

## GitHub Pages로 올리기 (지인용)

1. GitHub에서 새 저장소를 만들고 이 폴더 내용을 업로드
2. Settings → Pages → Branch: `main` / `(root)` 선택 후 저장
3. 나온 주소를 지인들에게만 공유

참고: 무료 계정은 비공개(private) 저장소의 Pages를 쓸 수 없어요. 주소를 아는 사람만 접속할 수 있는 건 아니라서, 완전 비공개가 필요하면 유료 플랜이나 다른 호스팅(비밀번호 걸기 등)을 고려해야 해요.
